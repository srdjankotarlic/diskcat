📀 About DiskCat

DiskCat keeps track of which drive holds the footage from which shoot — so you find it in seconds instead of digging through drives.

Find footage

Type a shoot name, filename, project/root folder, client, tag or year in the search — you'll see which drive(s) it's on. Or open Drives and click one.

Add footage

Click ＋ New entry, name it, set the date, add the project/root folder if one exists, tick which drive(s) it's on (tick 2+ = backed up), add client / tags / stage. Save.

Folder inventory

Click Folder inventory to scan a folder locally in Chrome/Edge or paste a file list. DiskCat stores searchable names and paths, not your media files.

Backups

Footage on 2+ drives shows ✓ backed up. The top counter shows how many shoots are not backed up yet.

Your data

Local mode stores data in this browser only. Optional Cloud sync uses the Supabase project you enter; DiskCat does not host your cloud data.

Install (phone)

Browser menu → Add to Home Screen. It then works like an app, even offline.

Setup steps

  1. Create a free Supabase project.
  2. Run the DiskCat SQL in that project.
  3. Paste the project URL and anon/publishable key below.
  4. Save, sign in, then create or open an archive.
