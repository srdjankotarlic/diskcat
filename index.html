📀 About DiskCat

DiskCat keeps track of which drive holds the footage from which shoot — so you find it in seconds instead of digging through drives.

Find footage

Type a shoot name, client, tag or year in the search — you'll see which drive(s) it's on. Or open Drives and click one.

Add footage

Click ＋ New entry, name it, set the date, tick which drive(s) it's on (tick 2+ = backed up), add client / tags / stage. Save.

Backups

Footage on 2+ drives shows ✓ backed up. The top counter shows how many shoots are not backed up yet.

Your data

Everything is stored in this browser only — nothing is uploaded. Use Export for a backup file; Import to restore or move to another device.

Install (phone)

Browser menu → Add to Home Screen. It then works like an app, even offline.

Shortcuts

/ search · N new entry · Esc close
